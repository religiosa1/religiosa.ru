---
title: Склонение весёлых существительных
---

По аналогии со [спряжением](./konjugacija), есть ряд склонений, который
вызывает у меня проблемы.

Аналогично, решил выписать, чтобы уже помнить.

## Винительный падеж после предлога "о"

Ряд глаголов использует винительный падеж в подчинение существительного после
предлога "о". Надо их просто запомнить.

- dbać o (młodszą siostrę/dobrą atmosferę)
- pytać o (nowego nauczyciela/ważną sprawę)
- prosić o (pomoc/dodatkową godzinę)
- starać się o (nową pracę/stypendium)
- walczyć o (wolność/lepszą przyszłość)
- martwić o (młodszego brata)

В большинстве "нормальных" случаев будет предложный как всегда, но вот эти
исключения надо запомнить.

## Miesiąc/pieniądz

Оба эти существительных имеют чередование ą/ę которое мне постоянно поджигает
голову. Надо запомнить -- чередуется только во множественном числе в
родительном и творительном падежах.

### Pieniądz

| przypadek   | liczba pojedyncza | liczba mnoga |
| ----------- | ----------------- | ------------ |
| mianownik   | pieniądz          | pieniądze    |
| dopełniacz  | pieniądza         | pieniędzy    |
| celownik    | pieniądzowi       | pieniądzom   |
| biernik     | pieniądz          | pieniądze    |
| narzędnik   | pieniądzem        | pieniędzmi   |
| miejscownik | pieniądzu         | pieniądzach  |
| wołacz      | pieniądzu         | pieniądze    |

## przyjaciel/przyjaciółka

Просто дурацкое склонение в довольно распространённом существительном.

| przypadek   | liczba pojedyncza | liczba mnoga  |
| ----------- | ----------------- | ------------- |
| mianownik   | przyjaciel        | przyjaciele   |
| dopełniacz  | przyjaciela       | przyjaciół    |
| celownik    | przyjacielowi     | przyjaciołom  |
| biernik     | przyjaciela       | przyjaciół    |
| narzędnik   | przyjacielem      | przyjaciółmi  |
| miejscownik | przyjacielu       | przyjaciołach |
| wołacz      | przyjacielu       | przyjaciele   |

Во множественном числе происходит какой-то ад с чередованием e/ó. Правило
бутерброда действует, если считать вместе со звательным падежом.

| przypadek   | liczba pojedyncza | liczba mnoga   |
| ----------- | ----------------- | -------------- |
| mianownik   | przyjaciółka      | przyjaciółki   |
| dopełniacz  | przyjaciółki      | przyjaciółek   |
| celownik    | przyjaciółce      | przyjaciółkom  |
| biernik     | przyjaciółkę      | przyjaciółki   |
| narzędnik   | przyjaciółką      | przyjaciółkami |
| miejscownik | przyjaciółce      | przyjaciółkach |
| wołacz      | przyjaciółko      | przyjaciółki   |
